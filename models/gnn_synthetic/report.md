# Duration GNN - synthetic

120 projects in 120 independent groups, 2510 labelled activities, 5-fold project-grouped cross-validation (out-of-fold predictions).

| method | MAE days | MedAE days | MdAPE % | MAE log-ratio | mean project MAE |
|---|---|---|---|---|---|
| plan | 4.083 | 3.138 | 24.31 | 0.2986 | 4.045 |
| median | 2.341 | 1.719 | 14.9 | 0.1635 | 2.397 |
| category | 1.81 | 1.188 | 9.4 | 0.1161 | 1.828 |
| mlp | 1.633 | 1.09 | 8.61 | 0.1064 | 1.653 |
| gnn | 0.795 | 0.531 | 4.44 | 0.0531 | 0.791 |

GNN vs best non-graph method (`mlp`): -0.863 days MAE per project, 95 % bootstrap CI [-0.938, -0.796] -> GNN significantly better.

**SYNTHETIC DATA - pipeline test only.** Labels were generated by known rules; this shows the code can learn a graph-dependent effect, not real-world accuracy.
